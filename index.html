Out of Memory — Server Crashed
Your server ran out of RAM. All in-flight requests were dropped and the server is restarting.
What happened?
Each thread, process, and active request consumes memory. When total usage exceeds your RAM limit, Ruby's allocator fails and the process crashes — there's no graceful degradation.
Solutions
  • Upgrade your VPS to get more RAM
  • Remove threads or processes to lower baseline memory
  • Reduce traffic until in-flight requests finish before scaling
  • Use fibers — they cost ~0.5 MB each vs 18 MB per thread
